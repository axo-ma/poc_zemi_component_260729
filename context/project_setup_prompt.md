## Git-правила

- Используем только стандартный Git, без GitHub CLI.
- Все изменения коммитим и пушим напрямую в ветку `main`.
- Перед коммитом проверяем `git status` и `git diff`.
- Сообщение коммита формулируй самостоятельно по сути изменений.
- Не создавай отдельные ветки и pull request без явного запроса.
- Не включай в коммит посторонние файлы.
- После push подтверждай, что изменения дошли до `origin/main`.

Контекстные материалы проекта хранятся в папке `context` внутри репозитория. Презентация ZEMI уже добавлена в GitHub.
