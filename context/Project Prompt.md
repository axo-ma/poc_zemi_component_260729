# Универсальный шаблон

Используй этот шаблон для работы с любой системой, проектом или компонентом. Заменяй заполнители в угловых скобках только подтверждёнными значениями.

Не предполагаю пути, зависимости, политику веток или поведение развёртывания, если они не указаны явно. Если обязательное значение неизвестно, сначала найди его в доступном контексте или запроси уточнение.

## Стандартные маркеры

- ZEMI Instance отмечается ровно одним маркером в зависимости от среды: `.zemiinst_dev`, `.zemiinst_exp` или `.zemiinst_prod`.
- ZEMI Component отмечается маркером `.zemicomp`.

Перед работой проверь, что каталоги существуют, а маркеры находятся непосредственно в ожидаемых корнях.

## Git-правила

- Используй только стандартный Git, без GitHub CLI.
- Используй ветку `main`.
